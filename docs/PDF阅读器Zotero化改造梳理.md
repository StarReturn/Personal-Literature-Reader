# PDF 阅读器 Zotero 化改造梳理

> 日期：2026-10-02 · 状态：待确认优先级后开工
> 目标：把阅读页的 PDF 体验从"单页翻页器"升级到 Zotero 阅读器的核心水准，同时保持现有批注/页码链接/阅读位置记忆能力不回退。

---

## 一、现状盘点（我们已有的）

| 能力 | 现状 | 与 Zotero 差距 |
| --- | --- | --- |
| 翻页 | 单页渲染，按钮/页码输入 | ❌ 无连续滚动（最大差距） |
| 缩放 | −/+ 按钮 15%~300%，DPR 高清 | ⚠️ 无"适应页宽/实际大小"快捷档 |
| 导航 | 无 | ❌ 无缩略图栏、无大纲目录、无全文搜索 |
| 批注 | 文字选中高亮 + 框选 + 便签 + 列表抽屉 | ⚠️ 列表在抽屉非常驻；无选中浮条 |
| 位置记忆 | 页码+缩放+模式 | ⚠️ 改滚动后需记滚动偏移 |
| 布局 | PDF/分析/分栏（拖拽分隔） | ✅ 已超 Zotero（分栏对照是其弱项） |
| 页码链接 | 分析→PDF 跳转 | ✅ 独有优势，改造后必须保留 |

## 二、Zotero 核心体验逐项梳理与方案

### P0-1 连续滚动阅读（价值最大）
- 所有页垂直连续排布，滚轮/触摸板流畅翻阅
- **方案**：pdf.js 多页容器；IntersectionObserver 懒渲染可视页 ±2 缓冲页，远离页销毁释放内存（大 PDF 100+ 页可控）；当前页 = 视口中心页
- **连带改造**：批注层与文字层改为"每页独立 stage"（canvas + textLayer + SVG）；页码链接跳转变 scrollIntoView；位置记忆存滚动偏移
- 风险：工作量大头在此，是整个改造的地基

### P0-2 页面缩略图侧栏
- 左侧窄栏显示每页缩略图，当前页高亮，点击跳转，滚动时联动
- 方案：scale≈0.18 渲染小 canvas（同样懒加载）；Zotero 式可折叠

### P0-3 工具栏 Zotero 化
- 当前页码/总页（滚动实时更新）、缩放下拉（50%~400% + 适应页宽 + 实际大小 + 适应窗口）、上/下一页保留
- 方案：纯前端，随连续滚动一起做

### P1-4 大纲/目录面板
- PDF 内嵌书签树（Zotero 的 Outline）；无大纲的 PDF 自动隐藏
- 方案：pdf.js `getOutline()` + `getDestination()` 解析目标页码，树形组件点击跳页；无大纲时退化为"分析栏目导航"（跳到右侧分析对应栏）——我们的差异化

### P1-5 全文搜索
- 文档内搜索：关键词 → 结果列表（页码+上下文）→ 跳转并在该页高亮命中矩形
- 方案：全文索引已有（智能导入在用 getTextContent）；高亮矩形由 text item 的 transform/宽高计算
- 联动：可顺带覆盖"库内搜索"（现有标题/分析/笔记搜索的增强）

### P2-6 注释体验升级
- **常驻注释侧栏**（Zotero 左栏）：批注列表实时显示，点击双向定位；替代现抽屉
- **选中浮条**：选中文字上方弹出小工具条（四色高亮/备注/复制），替代"松开即生成"的隐式交互
- 方案：selectionchange 定位浮条；侧栏复用批注数据

### P2-7 其他（按需）
- 双页对开视图（连续滚动的容器宽 2 列，改动小）
- 深色/护眼模式（CSS 滤镜 invert + 色相旋转，批注色需校准）
- 旋转（偶用）

## 三、分期与工作量

| 期 | 内容 | 规模 |
| --- | --- | --- |
| 一期 | P0-1 连续滚动（含批注层/文字层多页化、位置记忆升级）+ P0-2 缩略图栏 + P0-3 工具栏 | **大**（地基，一次做透） |
| 二期 | P1-4 大纲面板 + P1-5 全文搜索 | 中 |
| 三期 | P2-6 注释侧栏+浮条 + 双页 + 深色 | 中 |

## 四、不做什么

- 不换 pdf.js viewer 整套方案（自带 viewer 与我们的批注/分栏/页码链接体系冲突，重造不如渐进改造）
- 不做 PDF 编辑（改文件）类功能
- Zotero 的同步/协作/标签体系（应用定位外）

## 五、验收要点（一期）

1. 500 页 PDF 滚动流畅、内存平稳（懒加载生效）
2. 缩略图点击/滚动双向联动正确
3. 批注（高亮/框选/便签）在滚动模式下每页正常工作
4. 分析页码链接跳转正确滚动定位
5. 重启恢复到上次滚动位置
